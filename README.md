# Games

## Pocket Flap

A mobile-friendly Flappy Bird-style arcade game, built with plain HTML, CSS, and JavaScript. No dependencies or build step.

Open `pocket-flap/index.html` in a browser, or serve the repository locally:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000/pocket-flap/.

Tap to flap; on desktop use Space or Arrow Up. Includes a locally saved best score, optional sound, and quick restarts.
